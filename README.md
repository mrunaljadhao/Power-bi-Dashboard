Sample Superstore Dashboard using Power BI

About the Project
This project is an interactive dashboard created using Microsoft Power BI to analyze Sample Superstore sales data.

Objectives
- Analyze total sales and total orders.
- Understand profit performance.
- Compare sales across product categories and regions.
- Identify useful business insights through visualizations.

Tools and Technologies
- Microsoft Power BI
- Power Query
- DAX

Dashboard Features
- Total Sales
- Total Orders
- Total Profit
- Sales by Category
- Regional Sales Analysis

Project File
The Power BI report file is available in this repository: "sampIII dashboard.pbix"
